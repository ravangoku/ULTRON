# Voice

The real-time target pipeline is microphone → VAD → STT → context → LLM → speech-performance controller → expressive TTS → speaker, with barge-in cancelling audio. The controller chooses pauses, rate, emphasis, pitch, and restrained style per sentence. Configure an original, licensed, human-sounding deep voice; no actor cloning, imitation, copyrighted samples, excessive vocoding, or claimed quality without provider validation. Test conversation, long/short phrases, questions, technical text, numbers, names, Tamil/English where supported, speeds, and interruption before release.
